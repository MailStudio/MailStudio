# MailStudio 0.5.0

MailStudio 0.5.0 is a stability and productivity release focused on Microsoft 365 reliability, better notifications, shared mailbox support, and a more useful daily workspace.

## Highlights

- Added a richer focus timer with 15m, 30m, 1h, and custom durations, a cleaner tile layout, and animated final-countdown states.
- Added command palette, centered shortcut/search overlays, recents, workspace controls, import/export, and expanded diagnostics pages.
- Added Teams status controls backed by Microsoft Graph presence support.
- Added automatic notification arming, per-provider notification diagnostics, cooldowns, and persisted baselines.
- Restored and hardened shared Outlook inbox discovery, including support for `outlook.cloud.microsoft`.

## Microsoft 365

- Improved Microsoft SSO by adding login hints, silent auth preference, session health sweeps, and soft repair before destructive session clearing.
- Routed Teams email-share links directly into the Teams tab.
- Added detection and recovery controls for blank Teams shells, including Teams retry/clear-cache actions and clearer diagnostics when Teams itself does not render.
- Kept shared Outlook mailboxes in the Microsoft session partition and prevented partial folder-tree scrapes from deleting existing shared inbox tabs.
- Prevented the primary mailbox from being duplicated as a managed shared mailbox.

## Notifications

- Centralized notification dispatch, cooldowns, delivery history, and persisted baselines.
- Mail notifications now require newly identified visible messages, reducing false alerts from unread-count churn or shared account backfills.
- Shared mailbox notifications track baselines per mailbox instead of using one global mail state.
- Notifications are armed automatically for connected providers.
- Added debugging views for notification history, baselines, cooldowns, and Microsoft auth events.

## Asana

- Classified Asana API failures more clearly, including workspace/trial permission failures and timeouts.
- Falls back to web scraping when the Asana API is blocked but the web session is still usable.
- Preserves stable Asana task permalinks and prevents duplicate connect attempts.

## Stability

- Added tab health, blank-page checks, prewarm state, feed staleness detection, service failure history, and exportable debug reports.
- Hardened delayed BrowserView work so stale or half-destroyed views do not crash the main process.
- Improved background feed refresh and prewarming so API-backed feeds refresh promptly and scrape-owned inboxes stay live.
- Added deep regression coverage for routing, notifications, shared inboxes, Teams recovery, settings, diagnostics, and release checks.

## Security And Permissions

- Microsoft permissions remain least-privilege for mail and calendar read access, with `Presence.ReadWrite` added only for Teams status set/reset.
- Custom pinned sites remain isolated to exact allowed hosts.
- Downloads, settings export, and local files keep owner-only and safe-protocol handling.
